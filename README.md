# Dreams of Adulthood Alpha

Play the [Playable Alpha Build](https://jizhijin.github.io/DreamsOfAdultshood-Alpha/) in a desktop browser with a keyboard and mouse.

The Alpha menu numbers its missions **1–6**. These correspond to the original missions **2 → 6 → 1 → 5 → 3 → 4**, in that order.

To open the Unity project, clone this repository and select its root folder in Unity Hub with **Unity 6000.3.23f1**. Add Web Build Support to build a browser version. Unity's enabled scene list defines the campaign order.

This Alpha was based on the [original team's main branch at f3de144](https://github.com/tianyu999forever/DreamsOfAdultshood/commit/f3de144fc1379544137fb8fbdfe7d3d136786012).
